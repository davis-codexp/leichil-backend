SKYNET is a project created, maintained and hosted by CodeXP. This project provides services for our core functionalities such as automated email, file upload to cloud, SMS service, Image Compression, Video Processing, Push Notification, among others.

This project follows an Event Driven Architecture with multiple services subscribed to multiple channels/topics on the Message Broker.

The services are written in different programming languages such as Python, JS etc. while Rabbit MQ serves as the Message Broker
